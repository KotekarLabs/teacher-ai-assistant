# Teacher AI Assistant — Educational Quality Rules v1

## Pedagogical Excellence Standards
1. Learning Objectives: State 2-4 concrete, measurable objectives using action verbs (e.g., Identify, Explain, Calculate, Compare).
2. Time Budgeting: Allocate time realistically so the introduction, explanation, activity, and assessment fit smoothly inside the total lesson duration.
3. Active Learning: Include at least one interactive, hands-on classroom activity that engages students collaboratively or individually.
4. Concept Progression: Move systematically from prerequisite recall -> intuitive introduction -> deep explanation with examples -> guided practice -> independent quick check.
5. Teacher Script & Tone: Provide natural, conversational talking points that teachers can read or adapt in real-time.
