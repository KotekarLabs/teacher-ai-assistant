# Teacher AI Assistant — Product Bible v1.0
## Identity
AI-powered Teacher Productivity & Teaching Assistant SaaS; India initially; primary user: teachers.

## Positioning
Not a generic chatbot: a teacher's AI-powered daily workspace.

## Promise
Help teachers plan lessons, create teaching materials, conduct assessments and manage daily teaching workflow.

## Vision
PLAN → PREPARE → TEACH → PRACTICE → ASSESS → ANALYZE → IMPROVE.

## Problem
Teachers spend significant time preparing lesson plans, explanations, examples, activities, worksheets, quizzes, homework, answer keys, assessments and feedback.

## Differentiation
Specialized teacher workflow; structured classroom-ready outputs; curriculum/age awareness; reusable content; teacher review/control.

## Initial users
Primary/middle-school teachers; computer/coding/robotics teachers; science/math/English teachers; tuition teachers.

## Initial market
India, especially CBSE/ICSE/state boards, classes 1–10 and English-medium schools. Architecture remains curriculum-agnostic.

## Core loop
Teacher Need → AI Generation → Teacher Review → Classroom Use → Assessment → Student Results → AI Insights → Next Lesson.

## MVP
Authentication; Teacher Profile; Dashboard; AI Lesson Generator; Worksheet Generator; Quiz Generator; Homework Generator; Answer Key Generator; Lesson/Content Library; Basic Class Management.

## Lesson package
Overview; objectives; prerequisites; introduction; teacher explanation; examples; activity; practice; quick assessment; homework; optional teacher script.

## Future
Student app, parent portal, school ERP, live classroom AI, AI voice/avatars, automatic grading ecosystem, LMS, marketplace, community, advanced analytics, complex AI agents.

## Principles
Teacher first; classroom first; structured over generic; AI + human; simple by default; build for the future.

## Monetization hypotheses
Free; Teacher ₹299–₹499/month; Pro ₹799–₹1,499/month; institution custom. Validate before finalizing.

## Moat
Teacher workflow; curriculum intelligence; personalization; teaching history; student data; school ecosystem.

## Privacy/security
Secure auth, encryption, RBAC, audit logging, secure storage, minimal student data and no unnecessary sensitive student data in MVP.

## Success
Activation, time saved, usage, retention, quality, satisfaction.

## MVP done
Teacher can sign up, create/select class, enter requirement, generate/review/edit resources, save, return, export/use.
